# PakDrive365 — Production Car Rental Platform

> A production car-rental website developed and deployed for a real business.

**Live Website:** https://www.pakdrive365.com.au/

## Project Overview

PakDrive365 is a web-based car-rental platform that allows customers to explore available vehicles, view vehicle details, select rental information, and contact the business.

The project was customized, integrated with a PHP/MySQL backend, and deployed to a live hosting environment.

This public repository is a **portfolio/case-study repository**. It intentionally does **not** contain the complete production source code, production configuration, customer data, credentials, or private client files.
